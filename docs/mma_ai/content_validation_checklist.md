# Human Content Validation Checklist

Before stamping "Approved for Publication," verify every item on this list.

## Terminology
- [ ] Every SMC term matches terminology_lock.md exactly
- [ ] No banned terms appear anywhere in the module
- [ ] Naming conventions followed (XAUUSD, H4, M15, London session, Gate 1, etc.)

## Structure
- [ ] Module title present
- [ ] Learning objectives present (2–3 bullet points)
- [ ] Reading section: 300–600 words, max 4 sentences per paragraph
- [ ] Annotated chart referenced (exact filename, pre‑generated asset)
- [ ] "Why This Matters" callout present (2–3 sentences, no engine parameters)
- [ ] Practical exercise present (identification or calculation task, no trade instructions)
- [ ] Quiz present (3–5 multiple‑choice questions)

## Tone
- [ ] No hype language ("guaranteed," "easy money," exclamation marks)
- [ ] No fear‑mongering ("blow account," "destroy capital")
- [ ] No gendered pronouns
- [ ] No emojis in lesson text
- [ ] Disclaimer present at the bottom

## Boundaries
- [ ] No trade entry/exit/management instructions
- [ ] No real‑time price data
- [ ] No engine parameters or proprietary algorithm details
- [ ] No comparison to other signal services
- [ ] No profitability guarantees

## Chart
- [ ] Referenced chart file exists in /static/assets/learn/charts/
- [ ] Annotations follow chart_annotation_rules.md

## Final
- [ ] Reading time estimate is ≤ 12 minutes
- [ ] Version number and date assigned
- [ ] Previous version archived (if applicable)
