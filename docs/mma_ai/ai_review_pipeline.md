# MMAcademy AI Review Pipeline

## Overview
Every module draft passes through four stages before human approval.

## Stage 1 — Draft Generation
- Model: ChatGPT
- Input: Module brief (provided by Clinton)
- Output: Full module draft following the module template

## Stage 2 — Triple AI Review
Three independent Groq-hosted models review the ChatGPT draft simultaneously:

### Reviewer 1: Mixtral
- Flags factual errors, terminology violations, tone violations, structure violations
- See mixtral_review_prompt.md for reviewer's system prompt

### Reviewer 2: Gemma
- Same review criteria, independent evaluation
- See gemma_review_prompt.md for reviewer's system prompt

### Reviewer 3: LLaMA 8B
- Same review criteria, independent evaluation
- See llama8b_review_prompt.md for reviewer's system prompt

## Stage 3 — Filter & Revision
- If any reviewer flags an issue, the draft is returned to Stage 1 with reviewer notes
- If all three approve with no flags, the draft proceeds

## Stage 4 — Human Proofread
- Clinton (or a designated editor) reads the final draft
- Stamp as "Approved for Publication" or return for revision

## Chart Generation
- Charts are never part of the AI pipeline
- Pre‑generated by chart_renderer.py from real candles data
- Module references the exact filename
