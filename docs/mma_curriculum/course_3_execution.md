# Course 3 — Applied Execution & Risk Management

## Prerequisites: Course 2 (or solid SMC understanding)

| Module | Title | Practical Exercise |
|--------|-------|---------------------|
| 3.1 | Building a Trade Plan | Write a complete trade plan for a given chart |
| 3.2 | Position Sizing | Calculate lot size for a $1,000 account risking 1% with a 20‑pip stop |
| 3.3 | Risk‑Reward & Expectancy | Evaluate a setup: "Is the RR acceptable? Why or why not?" |
| 3.4 | Trade Life‑cycle Management | Track a real trade outcome through each life‑cycle step |
| 3.5 | Drawdown & Psychology | Write a personal risk management contract |
| 3.6 | Trading Journal Mastery | Create a 5‑trade journal from provided screenshots; identify one pattern |
| 3.7 | Recovery & Discipline Protocols | Design a personal "Stop Trading" checklist with 5 concrete triggers |

## Assessment
- Quiz: 15 questions, 70% to pass
- Practical submission: Full trade plan with entry zone, SL, TP1/TP2, position size, and RR justification. Groq AI provides feedback.
- Badge upon completion: Disciplined Trader
