# MMAcademy Module Versioning

## Version Format
- v1.0 — Initial publication
- v1.1, v1.2 — Minor edits (typo fixes, wording improvements within doctrinal rules)
- v2.0 — Major revision (content restructured, new chart, exercise changed)
- Version number and date are recorded in the module file

## Archive Rules
- When a new version is published, the previous version is moved to /docs/mma_curriculum/archive/
- Archive filename: {module_id}_v{version}_{date}.md
- Archives are never deleted

## Student Impact
- Students who completed a module on an earlier version are NOT required to re‑complete
- Their progress record references the version they completed
- If a student is in‑progress on a module when it is updated, they complete on the version they started

## Rollback
- If a published version contains an error, the previous version can be restored
- Follow the rollback policy in rollback_policy.md
