# MMAcademy Rollback Policy

## When to Rollback
- A published module contains a factual error
- A published module violates a doctrinal rule (terminology, tone, boundaries)
- A published chart contains a markup error
- A student reports a legitimate issue that passes review

## Rollback Process
1. Identify the affected module and the version with the error
2. Locate the previous archived version in /docs/mma_curriculum/archive/
3. Verify the previous version is error‑free
4. Restore the previous version as the active module
5. Record the rollback in a rollback log: date, module, reason, restored version
6. Flag the erroneous version in the archive as "ROLLED BACK — Do Not Restore"

## Student Notification
- Students who completed the erroneous version are notified that the module contained an error and has been corrected
- Their progress is preserved
- They are invited to review the corrected content but are not required to re‑complete

## Prevention
- All rollbacks are reviewed to improve the review pipeline
- Recurring issues are added to rejection_examples.md
