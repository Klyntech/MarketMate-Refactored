# MMAcademy Approval Workflow

## Authority
- Clinton has final approval authority over all Academy content
- A designated editor may be delegated to review and approve minor edits (v1.1, v1.2)

## Approval Gates
1. AI Review Gate — All three AI reviewers must approve the draft
2. Human Review Gate — Clinton (or designated editor) must stamp "Approved for Publication"
3. Chart Verification Gate — Chart file must exist and follow annotation rules

## What Requires Approval
- New module publication — Full pipeline
- Module revision (any version change) — Full pipeline
- Quiz question addition/editing — Human review only
- Typo fix (no version change) — Editor discretion

## Rejection
- Any gate can reject the content
- Rejection must include the specific rule violated
- Content is returned to the previous stage with notes
